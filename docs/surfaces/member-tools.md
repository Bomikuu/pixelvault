# Private member tools · 2026-10-30

## Intent and system fit

The audit extension makes the next factual action discoverable across borrowing and lending. It retains Manrope, PixelVault blue, semantic light/navy surfaces, canonical Shadcn controls and Tailwind composition. No feature stylesheet, new identity, fabricated chart history or debt-based reputation was added. Exact currency values stay static.

- The header bell opens a private action center with category and unread filters. Reading an update never dismisses a payment obligation. Message counts use the reader's private through timestamp; incoming messages refresh without changing focus.
- Saved offers stay member-owned. Two or three current offers can share one amount, payment frequency and count through the existing server calculator. Each proposed start date stays visible; alternate terms never silently replace an application or signed agreement. Unavailable offers are removable. Narrow comparison tables have a named, keyboard-focusable horizontal region and scrolling cue.
- Calendar dates use signed schedules in Manila time, ordered collection coverage and explicit partial/covered/overdue states. They are not payoff or settlement claims. Dates-only ICS exports omit people and amounts, and require re-export after schedule changes. Lender decisions show open applications without an existing loan, current reservations and meeting follow-ups; no automated approval or ranking.
- Form errors keep entered values, identify invalid controls and focus the first invalid field or general error. Help text and errors share unique per-form associations. Financial definitions have readable text and an expandable explanation.
- Native room calls are optional. Both parties explicitly join; microphone and camera permissions remain separate user actions. Camera starts off. Leaving, hiding, declining or ending stops capture; late device promises stop their tracks. Participant-only ephemeral SDP expires and is cleared. There is no recording. Direct connectivity without a TURN relay is limited.
- Investment agreements freeze exact terms and document hash. Contract acceptance and simulated funding are separate steps for each party. A contribution is not credited from an upload or proposal. FIFO allocation is limited to subsequent new loans under the offer, without automatic reinvestment. Collected principal, attributed interest share, reversals, losses, unused capital and proposed/confirmed simulated payouts remain separate. Public circles count distinct confirmed test contributors and preserve anonymity. No real transfer, withdrawable wallet or approved legal template is claimed.
- Recovery-email verification is distinct from contact evidence. Recovery links are single-use and time-limited; current email and password binding invalidate stale requests. Public requests queue the same worker operation and return the same response. Tokens are kept out of anonymous API responses; test email is captured locally.

## Delivery and inspection boundary

Meeting participants can open **View conversation & records** outside the entry window. This view reads the existing conversation, agreement and explicitly shared files without checking anyone in. It hides capture and document-sharing controls, disables decisions and sends no financial command. Return to the waiting room for scheduled participation. Existing completed borrowing rooms use this record mode too.

Seven original PNG scenes retain their provenance and pixels. Delivery uses 480/960/1440 WebP variants, with the largest variants approximately 53–114 KB. Route groups load through React lazy boundaries with a visible loading state.

This revision uses source review and the user-authorized browser pass only. It does not run builds, automated application tests, type/UI checks or detectors. New financial concurrency, reversal, recovery and native call behavior need dedicated regression coverage before production use. A visual screen is not evidence of actual provider settlement, a successful remote call, device permission cleanup or completed password recovery. Historical test counts elsewhere do not validate this revision.

The local migrations were applied without reseeding or creating loans. The visual pass uses the existing synthetic Maya and Elias accounts; temporary saved offers are removed afterward. No contract acceptance, funding, payout, password change, new identity upload or microphone/camera permission is performed for inspection. Existing negotiation schedules are outside their entry windows; shared call/contract actions therefore remain unexercised.
