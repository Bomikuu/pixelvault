# Private developer reference

Audience: active developer/admin staff. Primary job: find the actual request, authorization boundary, money units and success/error shapes, then follow a lifecycle. Hallmark app scope: **Read**. Preserve PixelVault’s blue/navy palette and local Manrope/glyph; keep Scalar’s familiar searchable operation navigation and code snippets.

The HTML shell, generated schema and allowlisted renderer assets share the same staff guard. They use private/no-store responses and Cookie variation. The page CSP restricts scripts, fonts and network connections to self; no hosted proxy, auth persistence, remote font, telemetry or request playground is configured. Viewing a staff operation does not grant its finance/reviewer/support permission.

155 registered operations have source-reviewed declarations and a generated inventory. Open-ended maps are limited to documented domain metadata, field errors and named definition dictionaries. Unknown new endpoint declarations fail schema export rather than silently becoming generic JSON. Permission/projection checks and contract validation remain separate, deferred release evidence.

Content: fixed source-controlled guides, concrete operation parameters, binary/SSE MIME types and synthetic examples with credential placeholders. No member fixtures, secret keys, signature material, arbitrary remote schemas or user-selected guide paths are embedded. See [developer reference setup](../api/README.md).
