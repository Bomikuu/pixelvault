# Brand asset provenance

The `BrandMark.tsx` P/keyhole glyph is a hand-authored vector interpretation of the user-supplied PixelVault board in `docs/brand/pixelvault-brand-reference.png`, created on 2026-10-28. It is not claimed as an original designer export. The wordmark is accessible text using the product UI face Manrope, not a claim that the reference typeface was identified. Source vector fidelity remains subject to brand-owner approval.

BadgeArt.tsx and AvatarArt.tsx now use original hand-authored vector scenes and fictional portraits inspired by the user's second illustration reference. They replace the initial medallion/Lucide badge treatment; no game or Reddit artwork was copied. Portable SVG exports accompany the source components. The two supporting product scenes were generated with the built-in image-generation tool and copied into apps/web/public/illustrations; prompts and reference provenance are recorded in docs/brand/illustration-prompts.md.

Manrope is self-hosted via @fontsource/manrope under the SIL Open Font License. Upstream Shadcn components are adapted from the registry source under MIT; Radix UI primitives provide interaction semantics.
