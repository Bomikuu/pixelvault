# Brand asset provenance

The `BrandMark.tsx` P/keyhole glyph is a hand-authored vector interpretation of the user-supplied PixelVault board in `docs/brand/pixelvault-brand-reference.png`, created on 2026-10-28. It is not claimed as an original designer export. The wordmark is accessible text using the product UI face Manrope, not a claim that the reference typeface was identified. Source vector fidelity remains subject to brand-owner approval.

BadgeArt.tsx uses original geometric medallion frames with Lucide pictograms (ISC licensed); no game or Reddit artwork was copied. Manrope is self-hosted via @fontsource/manrope under the SIL Open Font License. Upstream Shadcn components are adapted from the registry source under MIT; Radix UI primitives provide interaction semantics.
